## ✨ Features & Upgrades

- 💻 **Interactive CLI Terminal Modal**: Execute real bash-like portfolio commands (`help`, `about`, `skills`, `projects`, `accounts`, `resume`, `sudo hire`, `matrix`).
- ⚡ **Spotlight Command Palette (`Ctrl+K` / `⌘K`)**: Quick navigation, theme tools, and instant section jumps.
- 🌐 **Developer Accounts & Profiles Hub**: Dedicated showcase with direct links & copy buttons for **GitHub**, **LeetCode**, **LinkedIn**, **Personal Instagram**, **Content Creator Instagram**, **Twitter/X**, and **Google Drive Master Certificates Archive**.
- 🛠️ **Interactive Skills & Proficiency Meters**: Categorized tech stack tabs across Programming Languages, AI & ML, Linux & Tools.
- 🚀 **Projects Spotlight & Modal Viewer**: Real-world projects (Smart Campus Platform, Linux Utility Suite, Python Problem Solving Suite) with interactive feature breakdown modals.
- 📜 **Verified Credentials**: Cisco Python Essentials 1 & 2, Anthropic Artificial Intelligence Foundations, and direct Google Drive archive access.
- 🔊 **Native Web Audio SFX**: Synthesizer sound effects with mute toggle.
- 📱 **100% Responsive & Glassmorphic UI**: Engineered with React, Tailwind CSS, and Lucide icons.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/) + Custom SVGs
- **Celebrations**: Canvas Confetti
- **Deployment**: [Netlify](https://www.netlify.com/) (`netlify.toml` pre-configured)

## 🚀 Running Locally

```bash
# 1. Install dependencies
```
